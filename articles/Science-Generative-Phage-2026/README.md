# Science 2026：AI生成完整噬菌体基因组

论文：King et al. **Generative design of bacteriophages with genome language models**. *Science* 393, eaec2657 (2026).

## 文件

- `article_local.md`：内部分享/本地编辑版，使用 `images/...` 相对路径，Fig.1–6 已保留。
- `article.md`：公共 GitHub 文本版。由于当前 GitHub 仓库为 Public，不直接托管Science论文原图，只保留图片位置和中文图注。
- `images/`：从用户提供PDF裁出的Fig.1–6，用于本地内部阅读和排版。
- `figure_manifest.md`：图片对应关系、论文页码和用途说明。

## 如何编辑而不丢图片

解压整个文件夹后，保持 `article_local.md` 和 `images/` 的相对位置不变。在 Typora、Obsidian、VS Code 等编辑器中修改正文时，图片会继续显示。

如果以后把 GitHub 仓库改为 Private，可以把 `images/` 整个目录上传，并把 `article_local.md` 作为仓库在线版使用。

## 在线排版

当前 Public GitHub 版 `article.md` 不嵌入原论文图片。内部使用时建议直接在本地 Markdown 编辑器打开 `article_local.md`，或者在在线排版工具相应图片位置上传 ZIP 里的图片。
