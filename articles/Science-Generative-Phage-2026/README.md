# Science 2026：AI生成完整噬菌体基因组

论文：King et al. **Generative design of bacteriophages with genome language models**. *Science* 393, eaec2657 (2026).

## GitHub公开目录

- `article.md`：公共 GitHub 文本版。当前仓库为 Public，因此不直接托管Science论文原图，只保留图片位置和中文图注。
- `figure_manifest.md`：Fig.1–6的文件名、原图号、PDF页码和正文用途。

## 本地内部分享ZIP

完整ZIP另外包含：

- `article_local.md`：使用 `images/...` 相对路径的完整编辑版；
- `images/`：从用户提供PDF裁出的Fig.1–6；
- `README.md`；
- `figure_manifest.md`。

解压后保持 `article_local.md` 和 `images/` 的相对位置不变，在 Typora、Obsidian、VS Code 等编辑器里继续修改时图片不会丢。

如果以后把 GitHub 仓库改为 Private，可以把ZIP中的 `images/` 和 `article_local.md` 一并上传，直接作为带图在线版使用。
