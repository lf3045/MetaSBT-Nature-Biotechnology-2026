## 文章主线

研究分析61株 *D. catenulata*，从508,773个变异中构建群体结构，并对5株代表菌株进行长读长组装。作者发现Dici1/Dici2两个高拷贝DNA转座子；模式株CBS 565ᵀ含96个完整Dici1拷贝。约100代实验进化后，在两个菌株背景中直接检测到7个Dici1新插入和20个Dici2新插入，并观察到与Dici相关的染色体重排。跨真菌系统发育进一步支持Dici为ITm超家族中一个此前未描述的家族。
