## 使用提示

对照应与样本在各阶段共同处理并测序。decontam、SourceTracker、microDecon、SCRuB、Squeegee等工具依赖不同假设，不能代替采样和实验室污染预防措施。低生物量不是低总DNA量，尤其宿主相关样本需结合绝对微生物负荷、批次与对照判断。
