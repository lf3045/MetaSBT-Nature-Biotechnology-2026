# Nature Communications 2026：Breeding for beneficial microbial associations

论文：Rog I, Lutz S, Fesenfeld L, Hiltbrunner J, Bouwmeester H, van der Heijden MGA. **Breeding for beneficial microbial associations.** *Nature Communications* 17, 7695 (2026). DOI: 10.1038/s41467-026-76260-6.

## 文件结构

- `article.md`：在线排版版，图片使用 GitHub Raw 公网地址，适合复制到 didispace/OpenWrite 等在线 Markdown 编辑器。
- `article_local.md`：本地长期维护版，图片使用 `images/...` 相对路径。
- `images/`：论文主文 Fig.1–3。
- `figure_manifest.md`：图片对应关系、用途和许可说明。
- `downloads/NatureCommunications-Beneficial-Microbe-Breeding-2026.zip`：完整发布包。

## 后续修改

建议长期维护 `article_local.md`。只要它与 `images/` 保持当前目录关系，在 Typora、Obsidian、VS Code 等本地编辑器中图片不会丢失。

GitHub Actions 会把相对图片路径转换为 `raw.githubusercontent.com` 公网链接，生成 `article.md`，并重新打包 ZIP。
