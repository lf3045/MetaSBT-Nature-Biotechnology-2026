## 科学边界

主要结果是LECA深时基因树祖源与相对获得时间的推断。浮霉菌门和黏细菌门的祖源信号，并不直接证明曾发生额外的细胞内共生；微生物席垫和病毒中介属于可检验的生态学/转移情景。枝长比较无法给出绝对地质时间。
